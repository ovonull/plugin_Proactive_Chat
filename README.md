# 主动消息

让机器人像真人一样，在群里或私聊沉默一段时间后自己开口说一句。

## 它做什么

- 群里或私聊**沉默到设定时长**（默认 10 分钟），触发一次主动发言检查。
- 发言前先让 AI 判断「此刻开口自不自然」（默认开），通过才生成并发送。
- 生成时会参考最近几条聊天流水，顺着没接完的话题说，或开个轻量新话题。
- 连续主动**若干次没人理**（默认 3 次）就暂停，一直停到用户开口说话才恢复。
- 机器人自己发的不算「有人说话」，不会自己把计数洗掉。

## 和定时提醒的区别

「循环定时提醒」是按固定间隔机械推送；本插件是**看沉默和氛围**——有人聊就不打扰，冷场了才考虑开口，且会克制连续主动。

## 使用前准备

在插件管理页给本插件勾选能力。前 4 项缺一不可，后面两项按需开：

| 能力 | 用途 |
|---|---|
| `msg.send` | 主动发群消息 / 私聊消息（必需） |
| `llm.generate` | 开口评分与生成主动消息（必需） |
| `plugin.storage` | 存每个会话的沉默时间与未回复计数（必需） |
| `scheduler.register` | 注册周期巡检任务（必需） |
| `msg.history` | 读最近聊天流水当参考（可选，没授权就按没上下文发言） |
| `cache.kv` | 进程内短时缓存，预留，当前不用也能跑 |

无需修改后端。插件用的是宿主现成的通用能力。

## 配置项

| 配置 | 默认 | 说明 |
|---|---|---|
| 沉默触发阈值（分钟，1～1440） | 10 分钟 | 自最后一条真人消息起计时；测试时可填 1 分钟快速验证 |
| 未响应次数上限（1～20） | 3 次 | 达到上限后暂停主动，用户发言后复位 |
| 巡检周期（秒，最小 10） | 30 秒 | 宿主唤醒插件执行会话巡检的间隔 |
| 群聊开口前评分（私聊豁免） | 开 | 群聊关闭后按概率直接触发；私聊不启用评分 |
| 插话概率（0～1） | 0.4 | 群聊在评分通过后触发，私聊直接触发；值越低越克制 |
| 群聊主动发言 / 私聊主动发言 | 都开 | 分别控制两类会话的主动能力 |
| 历史上下文条数（1～30） | 12 条 | 生成主动消息时参考的最近流水条数 |
| 免打扰时段（24 小时制） | 23:00-07:00 | 时段内不执行主动发言 |
| 群聊 / 私聊发言动机提示词 | 内置默认 | 留空使用内置模板；可自定义发言风格 |

## 使用效果

装好并授权后无需任何命令：

1. 在群里说话或私聊机器人 → 插件记下时间，重置未回复计数。
2. 沉默 10 分钟 → 插件唤醒。群聊评分通过、或私聊掷中概率后，发一条自然的主动消息。
3. 你回话 → 计数归零，重新计时。
4. 你一直不回 → 到第 3 次主动后暂停，不再打扰，直到你开口。

日志里搜 `主动聊天` 能看到每次评分、生成、发送和暂停的记录。运行记录页也能看到主动消息的模型调用。

## 常见问题

**装了但没有主动消息？**
- 检查 6 项能力是否都授权了，尤其 `scheduler.register` 和 `llm.generate`。
- 确认不是免打扰时段。
- 确认沉默时间已到（默认 10 分钟），且巡检间隔（默认 30 秒）已到点。
- 看日志里评分是否一直未通过——可以把「开口前先评分」关掉先验证发送链路通不通。

**主动发得太频繁 / 太冷淡？**
- 调大「沉默多久」或「连续几次没人理就暂停」。
- 调小「插话概率」，让它更少开口；调大则更活跃。
- 调大「参考最近几条聊天」让生成更贴合话题。
- 自定义动机提示词，写清楚你想要的说话风格。
